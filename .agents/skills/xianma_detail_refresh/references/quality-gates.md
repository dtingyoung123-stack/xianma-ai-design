# 质量门禁与交付记录

## 1. 生成前校验

- 图片数量在 1–9 张，顺序明确，角色无重复或缺失。
- `mode` 明确，商品来源和 `immutable_facts` 非空。
- 主体替换时，新主体参考图索引真实存在；原图只作为版式/语义参考。
- 组级视觉系统只生成一次，所有屏复用同一份内容。
- 已指定风格锚点；组级视觉系统包含可检查的颜色占比、服装、背景、标签和禁止项。
- 用户文案已逐字分配到对应图片；无未替换占位符。
- 每张原图的像素宽高已记录，作为最终交付尺寸事实源。
- 同一提示词不存在“要求某元素”与“禁止该元素”的冲突。

## 2. 生成后逐张检查

### 商品

- 商品身份、轮廓、比例、颜色、材质、Logo、部件数量和关键结构正确。
- `replace_product` 不得出现旧主体的颜色、支撑结构、扣具或材质残留。

### 物理关系

- 穿戴或摆放关系合理，沿曲面贴合。
- 有必要的遮挡、接触阴影和透视；无悬浮、穿透、透明或异常变形。

### 内容与角色

- 文案、数字、单位、Logo 和标签逐字正确。
- 场景与文案匹配；结构图箭头和标签指向正确。
- 详情角色、顺序和版式边界保留。

### 尺寸与确定性元素

- 最终交付图像素宽高与对应原图一致；模型原始结果单独保留。
- 生成图与原图宽高比不一致时不得直接拉伸，当前图片退回构图或画布合成处理。
- 文字、数字、Logo、箭头和标签优先使用确定性合成；由模型生成时必须由 AI 逐字逐项检查。无法确认正确时判定 `copy=fail`，不得要求运营执行额外确认。

## 3. 整组检查

- 所有图片共享同一色调、光影、字体、装饰语言和空间家族。
- 同一商品在不同角度和场景下的材质、结构、配色保持一致。
- 没有某一张回退成旧商品或独立生成成另一套风格。
- 版式来源图没有把旧配色、旧服装或旧装饰带入新视觉系统。

## 4. 判定与重试

硬性失败项：商品身份/结构错误、旧主体残留、商品悬浮或穿透、文案/参数错误、角色错配、箭头语义错误、交付尺寸错误、整组风格不一致。任一命中，该张不可交付。

轻微裁切、背景装饰偏差或光影差异可作为告警，但不得掩盖硬性失败。

单次 API 成功只代表获得内部候选图。候选图可保存到 `raw`，质量失败保留为 `rejected` 证据；这些都是 Skill 内部文件层，不得新增为平台用户状态。只有质量项全部为 `pass` 时，才允许调用 `scripts/promote-passed-image.ps1` 按源图尺寸生成平台成功结果。平台下载、点赞和单图编辑沿用现有规则，人工反馈不参与质量判定。

只重试失败图片，每张最多自动重试 3 次。每次记录：`screen_index`、`version`、`failure_type`、`changed_section`、`prompt_snapshot`、`task_id` 和结果路径。达到上限仍不合格时返回该图片失败，不得降低质量标准。

## 5. 交付记录

每张结果至少保留：

```json
{
  "screen_index": 1,
  "role": "hero",
  "mode": "replace_product",
  "product_source": ["..."],
  "prompt": "...完整提示词...",
  "model": "...",
  "task_id": "...",
  "version": 1,
  "quality": {
    "product": "pass | fail",
    "physical_fit": "pass | fail",
    "copy": "pass | fail",
    "role": "pass | fail",
    "group_consistency": "pass | fail"
  },
  "attempt_status": "success | failed",
  "result_status": "pending | success | failed",
  "output_path": "..."
}
```

`result_status=success` 仅在五项质量检查全部通过后写入；平台反馈、下载和单图编辑状态不属于本记录。

## 6. 推荐测试矩阵

| 用例 | 输入 | 必查重点 |
|---|---|---|
| P-01 | 原护腰详情组，不替换商品 | 商品主体不变、组级风格、文案/尺码数据 |
| R-01 | 同一详情组 + 新护腰正面/侧面图 | 新主体统一、旧结构排除、场景贴合 |
| R-02 | 主体替换结构卖点图 | 商品层、箭头端点、标签语义、无悬浮 |
| E-01 | 单张失败或不满意 | 仅当前图重试，其他图版本不变 |

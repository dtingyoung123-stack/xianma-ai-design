# 角色四视图提示词补充规则 PRD

- 版本：V1.0；日期：2026-10-20。
- 状态：用户已确认产品规则；本地原型实现，未接真实模型、未上线。
- 范围：无限画布图片节点的角色四视图模式，仅补充输入与提示词组装规则。
- 来源：用户明确要求“选择了四视图依然支持输入提示词，底层提示词就是默认四视图提示词＋用户输入内容”。本规则覆盖此前四视图模式隐藏输入框的行为。

## 交互规则

1. 选择设定图→角色四视图后，提示词输入框仍可编辑；放大编辑与卡片共用同一份输入。用户只看到自己填写的内容，完整默认提示词不在页面展示。四视图输入框占位文字为“基于关联角色图，生成面部近景、正面、侧面和背面全身合图。”，仅在输入为空时显示，输入后消失，不单独显示为说明段落；放大编辑一致。占位文字不是用户输入，不写入实际请求提示词。
2. 输入可选；仅空白按未填写处理，不阻止生成。仍必须关联有效角色图片，多图时必须选择一张；文字不能替代参考图。
3. 切换模式不清空用户输入。退出四视图后普通模式只使用用户输入，不携带默认四视图正文。
4. 四视图固定3:2、1536×1024、1张，不因用户输入而开放规格修改；退出后恢复普通模式参数及可编辑状态。生成期间输入暂时禁用。
5. 结果回填当前目标图片节点并保留结果版本，不另建节点。提示词模板选择在四视图期间保持禁用，本次仅开放手动输入与放大编辑。

## 底层组装与记录

- 默认使用已定档的角色四视图提示词，不修改原始正文；提示词配置版本由开发维护并随任务保存。
- 非空：实际请求提示词＝默认四视图完整正文＋两个换行＋“【用户补充要求】”＋换行＋去除首尾空白的用户输入。
- 空输入或纯空白：实际请求提示词仅为默认正文，保持原文不变，不附加空标签。
- 每次提交均从默认正文和独立用户输入重新组装，不从上次完整提示词追加，避免重复叠加。
- 提交时保存默认模板版本、默认正文、用户输入原文、拼接后的实际提示词、参考图及输出参数快照，与本次任务及结果版本关联；后续编辑不得改变历史快照。
- 保留既有每次输出及失败记录、生成状态与验收状态记录要求。生成成功不等于效果验收通过。
- 不新增用户文本过滤、自动改写或冲突优先级机制。固定规格由平台参数控制；用户内容与四视图结构矛盾时的模型遵循效果需实际生图验证，不承诺必然符合。

## 验收标准

| 编号 | 操作 | 预期 |
|---|---|---|
| AC01 | 四视图输入并打开放大编辑 | 可输入，同步显示用户内容，不展示默认正文 |
| AC02 | 空输入/纯空白提交 | 仅使用角色四视图提示词 |
| AC03 | 输入“米色短裤与运动鞋”提交 | 默认正文在前，用户补充在后，原文和实际提示词分别留档 |
| AC04 | 连续提交、修改后再次提交 | 默认正文不重复，历史提示词快照不变 |
| AC05 | 有输入但无关联图 | 生成禁用，提示关联参考图 |
| AC06 | 切换四视图/普通模式 | 输入保留；四视图3:2锁定；普通恢复原比例且不附加四视图正文 |
| AC07 | 生成完成 | 回填同节点，新增结果版本并关联当次参数快照 |

## 验证边界与关联资料

当前原型使用固定角色样图，仅能验证交互、组装逻辑和版本记录；不能证明用户补充内容已影响实际图像。新增补充内容的真实模型效果尚待生图验收。

默认提示词及尺寸依据同目录《角色四视图最终提示词与开发交接_V1.0_261019.md》，其固定正文不在本补丁重复维护。正式源位于知识库角色四视图效果测试_261019目录，项目docs同名文件为开发副本。

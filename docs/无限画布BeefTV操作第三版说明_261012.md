## 操作流程

1. 空画布中央创建网格 / 底部 + / 双击空白 / 空白右键都使用同一份节点命令。文本、图片、视频、音频可创建；工作流保留禁用规划入口，不宣称具备分享或执行能力。
2. 单排底部主工具栏包含选择、抓手、新增、上传、素材、历史、撤销重做；缩放位于侧边。V为选择，H为抓手；空格+拖动或中键平移，鼠标滚轮按指针位置缩放，触控板平移。
3. 拖动节点；空白拖动框选；Shift追加、Ctrl切换、Alt移除；选中节点可整体拖动。右下角调整节点宽度。
4. 从节点右侧连接点拖到另一节点建立引用连线；拉到空白打开创建菜单，选类型后创建并自动连接。双击线删除。
5. 节点右键可创建副本或删除；多选复制重映射节点ID并仅复制内部连线；撤销重做仅当前会话。未实现生产运行状态隔离或分享工作流。
6. 图片上传/示例素材入画布，提示词设置、比例记忆、模拟生成、当前节点结果回看与加入画布、图片下载用于操作演示。图片生成固定返回既有演示图；视频/音频不产出真实媒体。
7. 第三版使用独立、按项目分区的本地演示快照，刷新保留节点、连线、视口；不读取或覆盖旧版数据。保存失败时标记“仅当前会话”。
